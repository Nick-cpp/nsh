# nsh
Minimalistic shell

---

# Installation

## 1. Download the latest release and extract the source code

```$ wget https://github.com/Nick-cpp/nsh/archive/refs/tags/1.1.tar.gz```

```$ tar -xvf 1.1.tar.gz```

## 2. Building the nsh

```$ cd nsh-1.1```

```$ make```

## 3. Installing the nsh for your user

```# make install```

```# echo /usr/local/bin/nsh >> /etc/shells```

```$ chsh -s /usr/local/bin/nsh```
