# nsh
Minimalistic shell

---

# Installation

## 1. Cloning the repository

```$ git clone https://github.com/Nick-cpp/nsh```

## 2. Building the nsh

```$ cd nsh```

```$ make```

## 3. Installing the nsh for your user

```# make install```

```# echo /usr/local/bin/nsh >> /etc/shells```

```$ chsh -s /usr/local/bin/nsh```
